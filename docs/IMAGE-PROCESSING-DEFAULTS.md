# 网站图片处理默认规则

本文档记录 E.O 图文网站当前默认采用的公开图片处理规则。今后如无单独说明，新专题、新文章、新封面和 AI 工坊相关图片，均优先按这里执行。

## 1. 适用范围

适用于本仓库内用于网页公开展示的图片派生文件，包括：

- 摄影专题页
- 旅行栏目
- 文字栏目
- 首页与目录页入口图
- AI 工坊中由本人拥有公开使用权的 AI 图片

不适用于原始照片保存，不适用于第三方授权图片、截图、Codex 生成图片等特殊来源素材的版权改写。

## 2. 输出格式与规格

- 保留原始源文件，不覆盖。
- 网页公开图默认导出为新的 `WebP` 文件，并使用新的、稳定的文件名接入页面。
- 默认响应式宽度规格为：`640 / 960 / 1600 / 2400`。
- 只生成不超过原图宽度的版本；若原图较小，则生成到原图可承受的最大宽度为止。
- 对部分较小图片、竖幅图片、AI 工坊卡片图或本身没有必要做超大图的素材，可少于四档，例如只生成 `640 / 960 / 1600`，或 `640 / 960`。
- 页面接入时默认使用 `srcset` 和 `sizes`，由浏览器按设备和布局自动选择合适版本。
- 普通页面预览图默认优先使用 `>=960` 的第一档；全屏查看或大图链接默认使用该图片已生成的最大版本。

## 3. 压缩与色彩

- 当前默认 `WebP` 质量基线为 `quality=88`。
- 当前默认编码方法为高质量优先的 `method=6`。
- 默认转换并嵌入标准 `sRGB ICC`。
- 画质优先于极限压缩；如果个别图片在 `Q88` 下出现天空断层、色带、肤色异常、纹理损失或阴影过脏，可单独提高质量，不强迫所有图片死守同一参数。

## 4. 元数据保留与删除

### 4.1 默认保留

- `EXIF ImageDescription`
  - 保留原片该字段原值。
  - 若原图为空，则导出图中也保持为空字段，便于今后统一读取。
- 标准 `sRGB ICC`
- 相机品牌、型号
- 镜头型号
- 焦距、光圈、快门、ISO 等基础拍摄参数
- 原始拍摄时间
  - 用于今后按拍摄年份或拍摄时间排序、筛选
  - 公开导出时默认不保留精确到秒、亚秒和时区信息；可归一到分钟粒度

### 4.2 默认删除

- 全部 `XMP`
- 全部 `GPS` 字段
  - 经纬度
  - 海拔
  - 方向
  - GPS 时间
- 相机和镜头序列号
- `MakerNotes` 厂商私有数据
- 精确到秒的拍摄时间、时区和亚秒时间
- 原始文件名、电脑路径
- Lightroom、Photoshop 等软件留下的完整编辑历史和内部标识
- 内嵌缩略图及其他无法确认内容的私有数据

## 5. 作者与版权字段写入

### 5.1 本人摄影作品

- `Artist` 统一写为：`E.O`
- `Copyright` 统一写为：`Copyright YYYY eomoment.com`

其中：

- `YYYY` 取该批导出图片首次用于网站公开发布的年份
- 2026 年首次发布的导出图写 `Copyright 2026 eomoment.com`
- 2027 年新导出的图片写 `Copyright 2027 eomoment.com`
- 以后按同一规律递推
- 年份跨年后，不为了“更新到新年份”而回头改写旧批次

### 5.2 本人拥有公开使用权的 AI 图片

- 默认沿用与本人摄影作品相同的作者和版权字段：
  - `Artist = E.O`
  - `Copyright = Copyright YYYY eomoment.com`
- 默认删除模型提示词、生成提示词或类似 `prompt` 残留信息
- 若 `ImageDescription` 实际上只是 Midjourney 等平台留下的提示词，不保留

### 5.3 不按默认规则改写版权信息的素材

以下素材不默认改写作者和版权元数据：

- 第三方授权图片
- 截图
- Codex 生成图片
- 其他来源不完全属于 E.O 原创版权的素材

这类图片如需格式转换，可只做网页接入与尺寸处理；版权归属应主要通过页面正文、图注或授权说明来呈现。

## 6. 页面接入默认做法

- 页面图片尽量使用 `srcset` / `sizes` 响应式接入。
- 目录页、首页卡片图和专题页入口图也纳入同一套响应式图片体系。
- 修改图片接入后，必须至少检查：
  - 本地页面实际是否正常加载
  - 是否存在坏链、404、空白图
  - `srcset` 与磁盘上实际生成的文件是否一致
  - 画廊页和单图查看器是否都能调用到正确的大图

## 7. 例外处理原则

- 少数特殊图片如果在默认参数下出现明显画质问题，可以单独提高质量或单独保留更大尺寸。
- 如未来专题需要使用公开图片中的拍摄年份、说明文字或部分拍摄参数，应优先复用当前保留的标准 EXIF 字段，不再重新手工补录。
- 如果未来网站迁移到 Cloudflare Workers Static Assets + R2，本规则仍然适用；托管位置变化，不改变公开图片元数据和导出规格的默认原则。
